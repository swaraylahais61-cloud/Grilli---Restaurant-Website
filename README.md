### Run locally

Clone the repository, then open `index.html` in a browser. No build step is required.
```bash
git clone https://github.com/swaraylahais61-cloud/Grilli---Restaurant-Website.git
```

Reservation and inquiry links open an email draft to `booking@grilli.com`; they require a configured email app.
